Footnote · RAG + MCP · sample

A document assistant that cites its source — or says it doesn’t know

Footnote answers questions from a set of documents and nothing else. Every answer names the page it came from, like a footnote. Ask it something outside the documents and it refuses, instead of guessing.

This is a recorded sample. The answers below are the real outputs of the app, run over three sample PDFs — a product guide, an FAQ, and a returns policy for a made-up outdoor brand. The full app, with live retrieval and an MCP server, is on GitHub.
